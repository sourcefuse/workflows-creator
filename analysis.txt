     WorkflowCreator Application - Documentation Plan

     Executive Summary

     The WorkflowCreator is a sophisticated Angular library that enables developers to build workflow automation tools
     with an intuitive, statement-based visual interface. It generates BPMN 2.0 compliant workflow diagrams, making it
     portable across various workflow engines.

     Package Name: @sourceloop/workflows-creator
     Purpose: Reusable UI library for workflow creation and visualization
     Key Technology: Angular 13.3.0 + BPMN 2.0 (bpmn-moddle)
     Architecture: Extensible plugin-based system with strategy patterns

       - Observer Pattern (EventEmitters)
       - Dependency Injection (Angular DI + multi-provider tokens)

     4. Core Components Deep Dive

     BuilderComponent (Main UI)

     - Location: lib/builder/builder.component.ts
     - Responsibility: Orchestrates entire workflow UI
     - Key Features:
       - Event management (triggers)
       - Action management (tasks)
       - Else block (alternative flows)
       - State synchronization with parent
     - Inputs: state, diagram, localizedStringMap, allColumns
     - Outputs: stateChange, diagramChange, eventAdded, actionAdded, itemChanged, actionGroupsAdded

     GroupComponent

     - Purpose: Renders event/action groups with AND/OR logic
     - Features: Add/remove nodes, group management

     NodeComponent

     - Purpose: Displays individual workflow nodes
     - Features: Input rendering, value editing, deletion

     TooltipRenderComponent

     - Purpose: Custom input field rendering
     - Supports: 15+ input types (text, email, date, people, etc.)

     5. Workflow Nodes Hierarchy

     AbstractWorkflowNode<E>
     ├── WorkflowEvent<E> (Triggers)
     │   ├── OnChangeEvent (column changes)
     │   ├── OnIntervalEvent (time-based)
     │   ├── OnAddItemEvent (new items)
     │   └── OnValueEvent (value checks)
     │
     └── WorkflowAction<E> (Tasks)
         ├── ChangeColumnValueAction
         ├── SendEmailAction
         └── [Extensible]

     AbstractBaseGroup<E> (Logic)
     ├── AndGroup (all conditions must match)
     └── OrGroup (any condition matches)

     6. State Management

     State Class: Immutable state with undo/redo
     - Map-based storage
     - Linked list of StateNodes (snapshots)
     - Methods: change(), undo(), redo(), get(), getAll()

     Statement Class: Workflow representation
     - Doubly-linked list of StatementNodes
     - Head/Tail tracking
     - Methods: addHead(), addTail(), splice(), append()

     7. Services Architecture

     Core Services:
     - BpmnBuilderService: Converts Statement ↔ BPMN XML
       - build(): Statement → BPMN diagram
       - restore(): BPMN XML → editable state
     - BpmnElementService: Element lifecycle management
     - BpmnNodesService: Node registration and retrieval
     - AutoLayoutService: Automatic diagram layout
     - LocalizationProviderService: i18n support
     - UtilsService: Shared utilities

     Service Layers:
     1. Abstract base services (extensible)
     2. BPMN-specific implementations
     3. Statement management services

     8. BPMN Integration

     Elements:
     - Start/End Events
     - Service Tasks (actual operations)
     - Exclusive/Parallel/Inclusive Gateways
     - Sequence Flows (connections)
     - Process containers

     Strategies:
     - Create Strategies: How elements are created
       - BasicStrategy, GatewayStrategy, TaskStrategy, etc.
     - Link Strategies: How elements connect
       - BasicLinkStrategy, GatewayLinkStrategy, NoLinkStrategy

     9. Extensibility & Plugin System

     Extension Points (via DI tokens):
     1. Custom Nodes: BPMN_NODES token
       - Extend WorkflowEvent or WorkflowAction
       - Register in module providers
     2. Custom Elements: BPMN_ELEMENTS token
       - Extend WorkflowElement
       - Define create/link strategies
     3. Custom Inputs: BPMN_INPUTS token
       - Extend WorkflowPrompt
       - Define validation/rendering logic

     Example Extension:
     @Injectable()
     export class CustomApprovalAction extends WorkflowAction<RecordOfAnyType> {
       name = 'Request Approval';
       inputs = [/* custom prompts */];
       // implementation
     }

     @NgModule({
       providers: [
         { provide: BPMN_NODES, useClass: CustomApprovalAction, multi: true }
       ]
     })

     10. User Interaction Flow

     1. Add Event: Click "When this happens" → select trigger → provide inputs
     2. Add Action: Click "Do this" → select action → provide inputs
     3. Group Logic: Combine with AND/OR groups
     4. Edit Values: Click nodes to modify
     5. Delete Nodes: Hover and click delete icon
     6. Else Block: Add alternative actions
     7. Export: Generate BPMN XML diagram
     8. Import: Load existing BPMN workflows

     11. Input Types Supported

     - Complex: Email (subject/body), People (multi-select)
     - Temporal: Date, DateTime, Interval, IntervalDate, IntervalTime
     - Selection: Lists, OptionLists, Criteria
     - Special: Percentage, Stepper, TimeZone
